# 实现范围与验收

依据：`design/gongdan-dashboard/设计说明.md` 和用户本次指令「先实现前端、后端，后续提供 MCP Server 对接数据库」。保留现有工单运营功能，不增加会话中心、知识库或其他底座产品模块。

当前为可运行的本地全栈应用，不是已接入客户数据库的生产系统。原设计稿保留；浏览器从 Node API 获取真实持久化的本地记录。UI 维持千蜂智服品牌、顶部 AI智能分析、连接管理分组和全局浮动 AI助手。

## 范围

实现入口和说明见 README。核心边界：

- `shared/domain.ts`：规范化客户数据、配置、工单、消息、分析和会话类型。
- `server/src/provider.ts`：后端本地提供器、校验、幂等、版本冲突及 MCP 待接入边界。
- `server/src/http.ts`：会话、角色、同源检查与 API。
- `server/src/store.ts`：仅用于本地开发的 SQLite、账号及加密凭据保存。
- `server/src/ai.ts`、`dates.ts`、`metrics.ts`：真实记录聚合、可选模型、周期调度与报告保存。
- `client/src/`：数据驱动的前端页面、操作确认和浮动助手。

前端分组和名称由客户数据提供；用户/租户和审计操作人只从后端会话取值。未配置 MCP 不访问原规格中的网络地址。界面没有切换 owner 角色的设计预览按钮。

## 验证记录

2026-09-06：TypeScript 检查、32 项 HTTP/周期/模型边界测试、客户端构建及 BeeMax 品牌色检查通过。测试使用独立临时数据目录。

浏览器实测：

- 管理员的连接凭据页仅显示只读状态；owner 写权限及明文不泄露由 HTTP 测试验证。
- 助手放大后实际鼠标拖拽由 960×820 调整为 827×716；切换还原与放大后保留尺寸和草稿。

审查结果分别处理：

- Standards：修复转派改写首次接单时间、跨期建议状态副本复活两项问题。
- Spec：修复跨期建议、助手只发送页面名称而没有业务上下文、查询中继续输入被回复清空三项问题；复查修复报告切换时助手标题不同步。
- 额外核对：确认表单保留打开时的版本，避免后台刷新让旧表单绕过冲突检查；自定义计划确认展示间隔、首次日期、时区与范围。

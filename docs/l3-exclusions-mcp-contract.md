# L3 部门全体通知：排除人员

状态：前端交互预览已实现，实际保存与通知执行待 MCP 服务端支持。以下是建议契约，不是现有工具。

## 用户期望

L3 支持「部门全体，排除指定人员」。管理员可添加排除人员、取消排除，并选择默认持续生效或仅今日生效。排除仅影响目标业务小组的 L3 通知，不删除员工、不退群、不影响 L1、L2、L4。

当前已核对的 MCP 工具提供 `get_roster`、`query_on_duty` 和 `set_roster`，但没有完整部门成员查询或明确的排除策略契约。当前排班只能表达 `@ALL` 或指定人员数组；不能将排班人员的并集视为部门全体，也不能添加一个远端未承诺执行的字段并显示保存成功。

## 服务端工作要求

请为 L3 增加原生排除策略，统一供工作台和真正执行升级通知的 Agent 使用：

1. 明确每个业务 `groupId` 对应的权威成员范围：企微部门或企微群。返回范围类型、名称和来源 ID，不能自动混用部门成员与群成员。
2. 提供成员查询，支持分页与搜索，返回稳定 `userId`、姓名、成员版本及完整性状态。选人结果须属于当前范围。
3. 保存 `all_except` 策略及 `excludedUserIds`，不能仅保存一次计算出的剩余人员名单。新成员后续加入时应自动纳入，已离开人员不应收到通知。
4. 每次 L3 升级发送前，按权威成员来源解析最新名单，减去排除人员，逐人生成定向提醒。存在排除项时不得使用 `@ALL`，也不得因查询失败降级成全体提醒。
5. 成员查询失败或结果不完整时不扩大通知范围，记录失败并返回可追踪状态；过滤后无人可通知时记录空名单状态，不发送广播。
6. 支持默认与今日覆盖，日期按 Asia/Shanghai 校验；今日覆盖到期恢复默认，修改默认不覆盖已存在的今日规则。
7. 写入做角色/租户校验、版本冲突检测、幂等处理、审计与原子保存。只修改目标小组 L3，不整体覆盖其他排班。

## 建议工具

- `list_notification_members({ groupId, cursor?, query? })`：返回权威范围信息、`members: [{userId,name}]`、`nextCursor`、`membershipRevision`、完整性状态。
- `get_l3_notification_policy({ groupId, scope, date? })`：返回 `revision`、`mode: all | people | all_except`、`members`、`excludedUserIds`、排除人员显示信息、当前生效来源及权威成员范围。
- `set_l3_notification_policy({ groupId, scope, date?, mode, members?, excludedUserIds?, expectedRevision, idempotencyKey })`：返回已持久化策略、最新版本和明确成功状态；出现版本冲突时拒绝覆盖。

以上名称可按服务端现有规范调整，交付时请提供实际工具 JSON Schema、错误码和响应示例。`set_roster` 与专用工具必须操作同一策略来源；旧工具不能悄悄清除已有排除项或把 `all_except` 当成 `@ALL`。

## 前端接入

当前已提供 L3「部门全体 · 排除指定人员（预览）」界面：可从当前小组已知排班中选人或手动填写姓名与企微 ID，添加/取消排除，并查看变更预览。界面明确显示尚未生效、候选非完整部门名单；关闭即丢弃，既不持久化也不调用远端写入。原有全体与指定人员保存路径保留。已通过实际浏览器添加、取消、空名单校验、预览及原有模式切换验证；93 项现有测试通过。

L3 编辑窗口增加「部门全体（排除指定人员）」。从权威成员列表搜索选择排除对象，展示排除名单及「取消排除」按钮。提交前预览目标群、范围、新旧排除名单。保存成功后读取服务端确认的策略。

页面文案采用「不 @ 这些人」。如果消息发在群里，被排除者仍可能看到群消息；此设置不保证消息不可见或设备完全无通知。如果要求这些人收不到消息，需要另行采用私聊发送方案。

## 验收

- 全体 A、B、C，排除 B：仅定向提醒 A、C，发送参数不含 `@ALL` 或 B。
- 新增成员 D 后，无须重新保存，下一次提醒包含 D；成员离开后不再提醒。
- 取消 B 的排除后，下一次提醒包含 B；非空排除名单始终禁止广播。
- 同一人员在其他级别的通知配置保持不变。
- 今日覆盖、跨日恢复、默认配置保留、重复提交、版本冲突均有测试。
- 未授权写入、跨租户访问、成员读取失败、分页不完整及空收件人有明确测试。
- 测试使用隔离环境与模拟发送器，不向实际客户群发送验证消息。

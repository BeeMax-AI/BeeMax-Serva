# PDF Chinese font

Noto Sans CJK SC Regular, from the [Noto CJK project](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf).

Distributed under the SIL Open Font License 1.1; see `LICENSE`. The unmodified font is embedded as a subset in exported PDFs. It is loaded only on the server, so deployment does not depend on installed system fonts or an external font service.

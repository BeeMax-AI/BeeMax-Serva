# 响应速度与稳定性修复（2026-09-06）

## 复现结果

- 导航：真实页面点击运营总览后 URL 已变化，配置页仍显示并等待 MCP 同步。隔离浏览器阻塞同步请求时，700 ms 后仍不能切换，每次导航额外发起一次 bootstrap。
- 工单详情：等待接口期间没有即时反馈；切页后迟到的响应重新打开已离开的工单。
- 年度统计：1000 条测试工单、366 天范围，同机单次基线约 235 ms；时间戳被按天重复扫描（回归测试读取 367165 次）。
- 真实服务还出现 ESCALATED_L3：旧状态枚举不支持，导致整份工作空间返回加载错误。

## 修复

- 已登录导航直接渲染当前同步快照，保留页面外壳。同步按用户配置周期或手动触发，导航不再重新同步或推迟同步时钟。
- 初次加载/刷新只读取一次 bootstrap；连续刷新共享在途请求。退出会话、数据写入更新会取消过时请求。
- 浏览器和服务端共用单次扫描统计，日期范围切换无需再请求 metrics；UTC+8、待闭环和平均时长口径保持一致。
- 工单详情立即显示加载状态，关闭/切页取消读取；复用弹窗时区分旧关闭事件，防止误取消新请求。
- MCP 的权限和审计读取与业务数据并行；工单详情去掉外层重复 workspace 读取，已知工单直接读取最新正文而非等待整库缓存重建；复用日期格式器。
- 补齐升级 L3/L4 的状态、筛选、重点关注与高亮展示。
